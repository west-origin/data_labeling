# ADR 0054: 프리라벨 시간 일관성과 손 3D 물리 제약

- 상태: 채택
- 날짜: 2026-10-23
- 관련: ADR 0008(프리라벨 어댑터), ADR 0015·0019(재실행·검수 보호), ADR 0044(손 맞춤 3D), ADR 0045(3D 표본
  방식·신뢰도), 실영상 파일럿 [pilot-real-2026-10-22.md](../handover/pilot-real-2026-10-22.md) 10절,
  문제 레지스트리 F-PAR-60·63.
- 계약 변경:
  - `KeypointFrame.interpolated` (선택, `true`만 실림): 앞뒤 관측 사이를 보간해 채운 키프레임.
  - `Trajectory3DSample.flags` (선택, `Constraint3DFlag` 목록 `reach`·`speed`·`accel`·`bone_length`):
    그 표본이 어긴 손 3D 제약. 둘 다 없으면 JSON에 싣지 않아 예전 라벨의 JSON·해시가 그대로다.
    `make schemas`. DB 스키마 변경 없음 (페이로드 JSON 안, Alembic 없음).
  - 정책: `prelabel.yaml hands.smoothing`·`hands.gap_fill`, `objects.track_filter`,
    `open_vocab_objects.track_filter`, `depth.constraints`. 각 절 해시가 그 단계 버전에 들어가 다시 돈다.
  - 손 어댑터 판 `sm1`, 3D 단계 판 `hf4 → hf5`.

## 배경

첫 실영상(342 s, 30 fps)에서 대리 지표(`dlp ops quality-proxy`)가 보인 것:

- OWLv2 도구 트랙 12,000여 개 중 약 69%가 키프레임 하나(500 ms 간격 추론 한 번)였고, 부엌에 없는
  욕조·변기 솔이 분당 수십~백여 트랙 떴다. COCO 박스도 사람·싱크 트랙의 70~90%가 0.5초 미만이었다.
- 손 트랙은 분당 70여 번 끊겼고 끊긴 구간의 약 80%가 0.5초 미만이었다. 손목 2D 떨림(2차 차분 / 손
  크기) 중앙값 0.07.
- 손목 3D 거리 표본의 25~31%가 0.15~0.9 m 밖, 약 5%가 3 m/s를 넘었다 (시각마다 따로 푼 배율이 튐).

정답이 없어 문턱을 정확도로 맞출 수는 없지만, 한 프레임만 뜨는 탐지와 한 표본만 튀는 3D는 물리적으로
드물다. 그래서 문턱을 모르는 상태에서도 안전한 시간·물리 일관성 규칙을 둔다.

## 결정

1. **객체·도구 박스 트랙 거르기 (`dlp_prelabel.temporal.filter_tracks`).** 탐지 문턱(min_score)은
   트랙을 잇는 문턱이고, 트랙을 여는 문턱(`track_filter.start_score`)을 따로 둔다 (히스테리시스). 여는
   문턱을 넘기 전 키프레임은 버리고, 남은 키프레임 수(`min_keyframes`)·길이(`min_duration_ms`)가 모자란
   트랙은 버린다. COCO 객체와 OWLv2 도구에만 쓴다. 지워지는 것은 라벨이 되기 전의 모델 출력이고, 이미
   검수된 라벨은 버전이 바뀌어도 지우지 않는다(ADR 0015).
2. **프라이버시는 거르지 않는다.** 블러는 재현을 우선하므로 짧은·깜박이는 블러 트랙을 지우지 않고 검수
   힌트로만 표시한다 (그룹 3, `dlp_privacy.hints`).
3. **손 2D 평활 (One Euro).** 정규화 좌표(0~1)에서 관절마다 One Euro 필터(`hands.smoothing`)를 건다.
   기본값은 보수적이다(합성 시험: 떨림 4 px에서 정지 오차 x0.8, 느린 동작 x0.9, 매우 빠른 동작 x1.2 지연).
   느릴 때 차단 주파수가 낮아 정지 떨림이 줄고, 빠를 때 높아 지연이 작다. `reset_gap_ms`보다 오래 끊기면
   새로 시작한다. 손 중심 3D 점(world)은 손 모양이라 평활하지 않는다. 평활한 2D가 라벨이 되며, 버전의
   `sm1`과 hands 절 해시로 밝힌다.
4. **짧은 끊김 채우기.** 같은 손이 `hands.gap_fill.max_gap_ms` 이하로 끊긴 사이의 실제 영상 프레임
   시각에 앞뒤 관측을 선형 보간한 키프레임을 넣는다. 채운 키프레임은 `interpolated=true`, 관절
   visibility 1(관측 아님)·신뢰도 `gap_fill.confidence`, world 없음이다. 3D 단계는 채운 키프레임을 올리지
   않는다 (지어낸 2D로 3D를 만들지 않는다). CVAT로는 보내지 않는 표시라 `quantize`가 빼고, 검수자가
   일부만 고친 트랙에서는 2D를 고치지 않은 키프레임에만 parent의 표시를 되살린다 (world와 같은 규칙).
5. **손 3D 물리 제약 (`dlp_prelabel.constraints3d`).** 3D 단계가 손 관절 표본에 검사한다:
   팔 길이 범위(`reach_m`), 손목이 한 표본만 튄 속도(들어오고 나가는 속도 모두 `max_speed_mps` 초과),
   가속도(`max_accel_mps2`), 세션 같은 손·같은 손끝의 손목 거리 중앙값에서 `bone_tolerance` 넘게 다른
   손끝(`bone_length`, 표본 `min_bone_samples` 이상일 때). 손목 표시는 같은 시각 손끝에도 붙인다 (한
   시각의 맞춤이 손 전체 배율을 정한다). 정책 `actions`가 표시마다 `downweight`(신뢰도 x `downweight`)
   또는 `drop`(표본 빼기)을 정한다. 남긴 표본은 `flags`에 어긴 제약을 그대로 싣는다. 기본: speed는
   drop(한 표본 튐은 거의 확실한 오류), 나머지는 downweight(기본 화각 근사처럼 배율 전체가 틀린 세션에서
   표본을 대량으로 지우지 않게).
6. **측정 기준과 필터 정책을 나눈다.** 대리 지표의 문턱(`evaluation.yaml proxy`)은 필터 정책
   (`prelabel.yaml`)과 같은 값으로 시작했지만 따로 둔다. 필터를 느슨하게 바꿔도 측정 기준은 그대로라야
   변화가 보인다.

## 결과

- 장점: 한 번 뜨는 오탐과 튀는 3D가 하위 단계(3D 궤적·접촉·관계·행동)로 덜 번진다. 표시는 남아 검수자와
  구매자가 어떤 표본이 의심스러운지 안다.
- 비용: 짧게 실제로 보인 도구(한 번 추론에 한 번)는 빠진다(재현 손실). 평활은 빠른 동작 시작에서 수
  프레임 지연이 생긴다. 채운 키프레임은 관측이 아니다 (표시로 구분).
- 내보내기: 3D 표본의 낮춘 신뢰도는 LeRobot 3D 신뢰도 특징에 그대로 실린다. `flags`·`interpolated`는
  이번에 내보내기 형식에 더하지 않았다 (후속, F-PAR-63). 채운 손 키프레임은 관절 visibility 1로 나간다.
- 문턱 값은 정답 표본으로 다시 정한다 (F-PAR-60).
