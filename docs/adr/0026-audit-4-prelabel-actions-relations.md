# ADR 0026: 감사 4차 — 프리라벨·행동·관계 단계 정정

- 상태: 채택
- 날짜: 2026-10-07
- 관련: WP8(프리라벨), WP9(관계), WP10(행동 구간), ADR 0010, ADR 0015, ADR 0019. 계약(dlp_schema)·DB 변경 없음.

## 결정

1. **검수된 결과 옆에 같은 대상의 모델 출력을 겹쳐 넣지 않는다.** 접촉·3D 단계는 입력 해시가 모델 버전에
   들어가 검수자가 입력을 고치면 다시 돈다. 검수된(승인·표본 검증) 결과와 사람 결과는 지우지 않으므로,
   새 결과 중 그와 겹치는 것을 버린다 (행동 단계의 `keep_protected`와 같은 원칙).
   - 접촉: 같은 손에서 시간이 겹치는 보호된 손 상태 구간이 있으면 새 구간을 버린다. 라벨 ID의 순번은
     원래 순번을 유지한다.
   - 3D 궤적: 같은 (개체, 부위, 좌표계)의 보호된 궤적이 있으면 새 궤적을 버린다.
2. **접촉 단계 버전에 장갑 압력 채널 접두사를 넣는다.** 접촉은 `sync.yaml glove.pressure_prefixes`로 고른
   채널을 쓴다. CLI가 동기화 정책에서 읽어 넘기고(`run_prelabel(pressure_prefixes=)`), 접두사가 입력 해시에
   들어간다. 바뀌면 접촉을 다시 만든다.
3. **착용자 사본은 모델 출처다.** 원래 트랙이 사람 출처여도 사본은 `Provenance(source=MODEL,
   model_version=wearer-…)`, 검수 전이다.
4. **VLM 서버 장애는 미상으로 쓰지 않는다.** 서버 오류·시간 초과는 `actions.yaml vlm.unavailable_backoff_s`
   만큼 기다리며 다시 묻고, 끝내 실패하면 `VlmUnavailableError`로 세션 실행을 멈춘다. 호출자 트랜잭션이
   되돌려지므로 아무것도 쓰지 않고, 서버가 돌아온 뒤 다시 실행하면 처음부터 만든다. 장애를 미상으로 채워
   정상 버전으로 쓰면 재실행이 같은 버전이라 건너뛰어 미상이 영구히 남기 때문이다. 응답 위반(스키마·온톨로지
   밖 값)은 종전대로 `max_retries` 뒤 그 구간만 미상이다. 백오프는 결과를 바꾸지 않아 정책 해시에서 뺀다.
   `dlp actions run`은 장애면 종료 코드 3을 낸다.
5. **트랙이 사라진 손.** 행동 단계는 hand21 트랙이 있는 손만 만들고, 트랙이 없어진 손(손 모델 버전 변경 등)은
   이 단계가 냈던 검수 전 행동·공백·설명만 지운다.
6. **관계·커버리지 중복.** 같은 (도구, 부위, 좌표계) 궤적이 여럿이면 검수된·사람 궤적, 그다음 최신 하나만
   쓴다. 커버리지는 (도구, 표면)마다 하나(작용부 접촉을 합친다)이고, 실행기는 내용이 같은 초안을 한 번만
   넣는다 (같은 ID 중복 삽입으로 실행이 실패하지 않게).
7. **COCO 학습 모델은 review.** COCO 주석은 CC BY 4.0이지만 이미지는 Flickr 사진마다 다른 CC 라이선스이고
   CC BY-NC 계열이 섞여 있다. EfficientDet-Lite0, YOLOX-m COCO를 `review`로 바꾸고 COCO 표기를 통일했다
   (ADR 0010 표 갱신). 허용 분류는 `[allowed, review]` 그대로라 정책 검사는 통과한다. 법무 확인에서 review를
   빼면 이 모델들도 대체 대상이다.

8. **타임라인 모델은 기준 스트림에서 한 번.** 마스터 타임라인 구간(stream_id 없음)을 내는 배포 모델
   (`prelabel.yaml timeline_predictors`, 이름은 `trained-<과제>`)은 기준 스트림(바디캠)에서 세션당 한 번만
   돌린다. 3인칭 스트림이 있으면 같은 접촉이 두 번 남던 문제다. 목록에 없는 모델이 다른 스트림에서
   타임라인 구간을 내도 버린다.

## 검수 작업과의 관계 (확인)

박스를 고쳐 접촉이 다시 만들어지면 검수 전 접촉은 지워진다. 그 접촉이 열린 Label Studio 작업에 있으면
`dlp_review.collect.drop_retracted`가 지워진 원래 라벨에 대한 승인·수정·삭제를 빼고 `stale`로 알린다
(되살리지 않는다). 새 접촉은 다음 검수 작업에서 다시 본다. 그 작업에서 새로 그린 구간(parent 없음)은 사람
라벨로 들어가므로 이미 만들어진 같은 시각의 새 모델 접촉과 겹칠 수 있다 (남은 한계: 새 모델 접촉은 다음
검수 작업에서 검수자가 지운다. 접촉 단계가 이후 다시 돌면 1번 규칙으로 그 사람 구간과 겹치는 접촉은 만들지
않는다).
