# ADR 0009: 모델 레지스트리와 실제 모델 연동 (RTMPose, OWLv2, 메트릭 깊이)

- 상태: 채택
- 날짜: 2026-10-07
- 관련: WP5, WP8. ADR 0008의 미연동 목록 일부를 대체한다.

## 배경

네트워크 정책이 열려 OpenMMLab·Hugging Face에서 가중치를 받을 수 있게 됐다. GPU는 여전히 없다.

## 결정

1. **모델 가중치는 `config/models.yaml` 한 곳에 적는다** (경로, sha256, 출처 URL, 라이선스). 정책 파일은
   모델을 이름으로만 가리킨다. `dlp_models.registry.resolve`가 파일 존재와 해시를 확인하고, 없으면
   `ModelUnavailableError`를 낸다. 어댑터는 이를 받아 건너뛰거나(프리라벨) 전수 검수로 넘긴다(프라이버시).
   - zip으로 배포되는 가중치(RTMPose, YOLOX)는 `archive_member`를 꺼낸다. sha256은 zip의 해시다.
   - 공개 ONNX가 없는 모델은 `export:` 스크립트로 공식 가중치를 직접 변환한다 (`make export-models`,
     일회용 PyTorch CPU 환경). sha256은 변환 환경의 기록이며 버전에 따라 달라질 수 있어 존재만 확인한다.
2. **추론은 ONNX Runtime(CPU)으로 통일한다.** GPU 서버에서는 `onnxruntime-gpu`로 바꾸면 된다.
3. **연동한 모델**
   | 용도 | 모델 | 라이선스 | CPU 속도 (이 환경) |
   | --- | --- | --- | --- |
   | 전신 17점 (MediaPipe Pose 대체) | YOLOX-m Human-Art + RTMPose-m Body7 (rtmlib) | Apache-2.0 | 실시간에 가까움 |
   | 청소·돌봄 도구 박스 (COCO 밖) | OWLv2 base ensemble, 양자화 ONNX (Xenova) | Apache-2.0 | 프레임당 약 7~9초 |
   | 블러: 문서·화면·사진물·문패·송장, 반사면 영역 | 같은 OWLv2 | Apache-2.0 | 같음 |
   | 손·객체 카메라 좌표 3D | Depth Anything V2 Metric Indoor Small | **모델 카드에 명시 없음** | 프레임당 약 0.4초 |
4. **느린 모델은 시간 간격(`frame_stride_ms`)으로만 추론한다.**
   - 프라이버시 OWLv2: 간격 사이 프레임에는 마지막 결과를 그대로 둔다(held). 같은 시각의 반복 호출
     (대상 탐지 + 반사면 영역)은 한 번만 추론한다. 기본 500 ms. 사이에 잠깐 나타난 대상은 놓칠 수
     있으므로 GPU에서는 간격을 줄인다.
   - 프리라벨 OWLv2 도구: 간격마다 키프레임을 두고 트랙으로 잇는다 (기본 500 ms).
   - 깊이: 기본 200 ms 간격으로 손 관절(손목·엄지 끝·검지 끝)과 객체 박스 중심을 역투영한다.
5. **3D 궤적은 카메라 좌표계(`frame=camera`, `source_3d=mono_depth`)다.** 내부 파라미터는 세션
   캘리브레이션을 해상도에 맞춰 쓰고, 없으면 정책의 기본 화각(90°)으로 근사한다. 월드 좌표는 카메라
   자세(SLAM)가 생긴 뒤에 만든다.
6. **OWLv2 점수는 원점수 / `score_full`로 0~1에 맞춘다** (프라이버시 정책). 재현율 우선으로 원점수 문턱을
   낮게(0.1) 둔다.

## 남은 미연동 (`make todo-models`)

| 기능 | 필요한 것 |
| --- | --- |
| 도구 작용부·파지부 마스크 | OWLv2 박스를 프롬프트로 한 SAM 2 마스크 추적 (GPU) |
| 카메라 6자유도 궤적 | 시각-관성 SLAM (Basalt, ORB-SLAM3) C++ 빌드, GPU |
| 영상 기반 학습 접촉 분류기 | 장갑 세션 정답 누적 후 WP13에서 학습 |

## 확인이 남은 것

- 메트릭 깊이 모델(Metric Indoor Small)의 라이선스. 상용화 전에 확인하고, 문제가 되면 상대 깊이
  모델(Small, Apache-2.0)과 스케일 보정으로 바꾼다.
- OWLv2 질의 문장과 문턱은 실제 바디캠 영상에서 골든셋으로 다시 정한다. 한국 가정의 물건(걸레, 밀대
  모양)에서 영어 질의가 잘 맞는지 확인이 필요하다.
- 광각 액션캠의 왜곡을 보정하지 않고 역투영한다. 캘리브레이션 왜곡 계수를 반영하는 것은 WP12(3D) 범위다.
- CPU에서 10분 영상(OWLv2 500 ms 간격)은 약 3시간이다. 실제 운영은 GPU 서버에서 돌린다.
