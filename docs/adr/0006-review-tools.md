# ADR 0006: 검수 도구 연동

- 상태: 채택
- 날짜: 2026-10-07
- 관련: WP6

## 결정

1. **하이브리드로 시작한다 (기준 문서 기본안).** 공간 라벨(박스·블러·키포인트 트랙)은 CVAT, 시간 구간 라벨(행동, 사이 구간, 상위 구간, 이벤트, 손 상태, 객체 상태)은 Label Studio에서 검수한다. 단일화 여부는 Gate 1에서 정한다.
2. **CVAT 변환은 PTS 인덱스로 프레임 번호와 ms를 맞바꾼다.** 우리 쪽에는 프레임 번호를 남기지 않는다. 키프레임 시각이 영상 프레임 시각과 맞지 않으면 보내기 전에 거부한다. 좌표는 소수 셋째 자리로 반올림해 보내고, 비교도 반올림한 값과 한다.
3. **Label Studio는 시간축이 ms인 시계열 라벨을 쓴다.** 프레임 변환이 필요 없다. 영상과 장갑·IMU 시계열(마스터 시각으로 옮긴 CSV)을 sync 그룹으로 함께 재생한다. 라벨 이름에 손을 넣어(`action.right:grasp`) 화면에서 새로 그린 구간도 손을 알 수 있게 한다. 화면에서 새로 그린 객체 상태 구간은 어느 개체인지 알 수 없어 받지 않는다.
4. **화면에서 고치지 않는 필드는 도구 쪽 메타데이터로 실어 보낸다.** CVAT는 트랙 속성(`dlp_label_id`, `dlp_meta`, 점별 `dlp_visibility`), Label Studio는 결과 id(원래 라벨 ID)와 `meta.text`다. 두 도구 모두 실제 서버를 거쳐, 고치지 않은 검수가 "모두 승인"으로 끝나는 것(무손실 왕복)을 테스트로 확인한다.
5. **검수 결과는 reconcile로 라벨 이력이 된다.** 바뀌지 않은 라벨은 검수 상태만 승인으로, 바뀐 라벨은 parent를 가리키는 새 human 레코드로, 지운 라벨은 retracted 레코드로, 새 라벨은 parent 없는 human 레코드로 남긴다. 새 레코드 ID는 내용 해시라 같은 결과를 다시 수집해도 중복되지 않는다. 한 작업은 한 번만 수집한다.
6. **역할 경계를 두 층에서 지킨다.**
   - 작업 수준: 프라이버시 검수는 원본 프록시를, 작업 라벨 검수는 라벨러 워터마크를 입힌 블러본만 쓴다. 일반 라벨러 경로에 원본 버킷이 보이면(s3 URI, path-style·virtual-host style 서명 URL 모두) 오류를 낸다.
   - 저장소 수준: 일반 라벨러 S3 자격 증명은 라벨링 버킷 읽기 전용이다. Label Studio 작업의 영상·시계열 URL은 이 자격 증명으로 서명하므로, URL이 새어도 원본은 열리지 않는다.
7. **라벨러 워터마크는 라벨러마다 영상에 새긴다** (`sessions/<세션>/review/<라벨러>/<스트림>.mp4`). 화면 캡처가 유출되면 출처를 알 수 있다.
8. **수집은 웹훅으로 일으킨다.** CVAT는 HMAC 서명(X-Signature-256), Label Studio는 비밀 헤더(X-DLP-Secret)로 확인한다.
9. **Label Studio 1.23은 새 조직의 레거시 토큰을 끈다.** 개발 환경에서는 `make up`이 부트스트랩 스크립트로 켠다. 운영에서는 개인 액세스 토큰(JWT)으로 바꿔야 한다.

## 확인이 남은 것

- 검수 화면 사용성 (사람 확인): 블러 누락 찾기 화면, 시간 구간·장갑 동기 재생, 워터마크 가독성.
- CVAT의 작업 단위 권한(조직·프로젝트별 원본 접근 권한자 분리)은 아직 도구 계정 수준에서 나누지 않았다. 지금은 원본이 CVAT 프라이버시 프로젝트로 복사되므로, 그 프로젝트는 원본 접근 권한자만 볼 수 있게 CVAT 조직을 나눠야 한다.
- Label Studio 영상 URL은 서명 URL의 만료(기본 7일) 안에서만 열린다. 오래 걸리는 작업은 다시 서명해야 한다.
