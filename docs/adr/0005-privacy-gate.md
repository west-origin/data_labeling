# ADR 0005: 프라이버시 게이트

- 상태: 채택
- 날짜: 2026-10-07
- 관련: WP5

## 결정

1. **모든 자동 모델은 공통 `Predictor` 계약(`dlp_schema.predictor`)을 따른다.** 프라이버시 탐지기는 프레임 단위 `FrameDetector`(이미지 → 탐지)를 구현하고, 추적기가 이를 묶어 `blur_track` 라벨로 낸다. 쓸 수 없는 모델은 `ModelUnavailableError`를 낸다.
2. **탐지기 구성은 정책 파일(`config/policies/privacy.yaml`)에 둔다.** 현재 이 환경에서 쓸 수 있는 실제 탐지기는 다음 두 가지다.
   - YuNet 얼굴 탐지 (OpenCV, CPU, 가중치 232 KB, `make models`로 받고 sha256 확인)
   - OpenCV QR·바코드 탐지 (가중치 없음, 송장 근거)

   Grounding DINO·OWLv2 같은 오픈 보캐뷸러리 탐지기는 이 환경에서 Hugging Face에 접근할 수 없어 `unavailable`로 둔다. GPU 환경에서 WP8과 함께 연동한다.
   **(갱신, ADR 0009)** 네트워크가 열린 뒤 OWLv2를 CPU로 연동했다. 문서·화면·사진물·문패·송장과 반사면 영역을 `open_vocab` 탐지기가 찾는다.
3. **탐지기가 없는 대상은 영상 전체를 `no_detector` 검수 구간으로 낸다.** 자동 탐지가 없다고 블러 없이 지나가지 않게, 사람이 전수로 본다. 검수 우선순위의 맨 앞이다.
4. **블러는 누락이 사고이므로 프레임을 건너뛰지 않는다.** 겹치는 여러 탐지기 결과는 합집합 박스로 합친다.
5. **트랙 유지는 앞뒤 모두 `blur_hold_ms`(기본 200 ms)다.** 소실 뒤 유지(기준 문서)와 함께, 처리가 오프라인이므로 첫 관측 앞으로도 미리 가린다. 탐지기가 대상이 처음 나타난 몇 프레임을 놓쳐도 노출되지 않는다 (합성 데이터에서 누락 25%일 때 이것 없이는 정답 2/460 프레임이 노출됐다). 짧은 끊김(`max_gap_ms`)은 선형 보간한다. 유지·보간 구간은 검수 우선 구간이 된다.
6. **블러본은 강한 모자이크(또는 단색)이며, 원본 PTS를 유지하고 오디오를 넣지 않는다.** 블러본은 라벨링 버킷(`sessions/<세션>/blurred/<스트림>.mp4`)에만 쓰고, 원본 버킷과 같은 버킷을 넘기면 거부한다.
7. **프라이버시 승인은 현재 블러 라벨이 모두 사람 검수(승인 또는 수정)를 거쳤을 때만 된다.** 표본 검증 상태도 승인에 쓰지 않는다. 블러본 렌더는 승인된 세션에서만 된다.
8. **잔여 누락 감사 표본은 (주, 세션, 스트림) 해시 순으로 고른다.** 같은 주에는 같은 표본이 나온다. 감사자가 원 블러 검수자와 같으면 거부한다. 최근 N주 연속 목표 이하일 때만 표본 검수로 전환하고, 최근 주가 목표를 넘으면 즉시 전수 검수로 돌아간다.

## 확인이 남은 것

- 실제 탐지 품질(얼굴·반사면·문서 재현율)은 파일럿 영상과 골든셋으로 판정해야 한다. 합성 테스트는 추적·보간·유지·렌더 로직이 정답 탐지에서 재현율 100%임을 확인한 것이다.
- 송장 전체 영역은 오픈 보캐뷸러리 탐지기(OWLv2, ADR 0009)가 맡고, QR·바코드는 근거로 함께 잡는다.
- 대상별 박스 여유(얼굴 20%, 그 밖 5%)는 실제 탐지기 위치 흔들림을 보고 조정해야 한다. 합성 실험에서 1 px 흔들림에도 작은 대상(사진, 송장)은 면적 일부가 여유 밖으로 나갔다.

## 갱신 (ADR 0019)

2차 전체 검수 정정이 이 결정을 보강한다. 바뀐 내용은 ADR 0019를 따른다.
