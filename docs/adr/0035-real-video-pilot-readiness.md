# ADR 0035: 실제 영상 파일럿 준비 검사와 입력 무결성

상태: 채택 (2026-10-09). 관련: WP3·5·6·8·12, ADR 0009·0034.

## 배경

첨부한 실제 손 영상에서는 PyAV RGB 배열의 행 패딩 때문에 MediaPipe 1.1이 손을 검출하지 못했다.
같은 프레임을 연속 메모리 배열로 전달하면 검출됐다. 모델이 없는 프리라벨 명령과 모델 이름의
오타도 성공으로 끝날 수 있었다. ZIP에서 꺼낸 모델의 캐시는 파일 존재만 확인하고 있었다.
스마트폰 표시 회전을 거부하는 기존 수집 경로에는 검증된 정규화 사본을 만드는 명령이 필요했다.

## 결정

- 공통 프레임 디코더는 연속 RGB uint8 배열을 반환한다. MediaPipe 두 어댑터의 버전에 `rgb1`을
  포함해 이전 예측과 구별한다. 이미 검수한 라벨은 기존 이력 보존 규칙을 따른다.
- `dlp prelabel run`은 선택한 모델을 준비하지 못하면 라벨·생애주기 쓰기 전에 종료 코드 1을 낸다.
  유효한 배포 모델이 기본 모델을 대체하는 경우는 허용한다. 선택 단계 제외는 `--skip`, 부분 실행은
  명시적인 `--allow-missing-models`를 사용한다. 부분 실행의 성공은 전체 준비 완료를 뜻하지 않는다.
- `dlp models fetch`는 알 수 없는 이름을 거부한다. ZIP과 추출 파일의 해시를 각각 검증하고,
  추출 파일의 `artifact_sha256`으로 캐시도 확인한다. 임시 파일을 쓴 뒤 원자적으로 교체한다.
  변환형 깊이 모델의 환경별 산출물 검증은 이 결정에 포함하지 않는다.
- 프라이버시 탐지기 참조의 순환을 명시적으로 거부한다. 라이선스 정책 순회도 순환 때문에 멈추지 않는다.
- `dlp media prepare`는 별도 H.264 MP4를 만들며 프레임 수·모든 영상 PTS·픽셀 크기·표시 회전과
  첫 오디오/데이터 트랙 정보·촬영 시각을 검사한다. 전체 트랙을 복사하고 지원하지 않는 트랙은
  FFmpeg 오류로 실패한다. 기존 출력은 덮어쓰지 않고 검증 후 같은 파일 시스템의 하드 링크로 공개한다.
  이미 라벨링한 세션의 영상 교체에는 사용하지 않는다. 오디오의 샘플별 동일성 검사는 추가하지 않았다.
- `dlp pilot check`는 손/청소 프로필의 모델 해시·라이선스 정책, 합성 영상의 실제 어댑터 실행,
  프라이버시 탐지기 초기화, 서비스 상태·DB 리비전·검수 계정 인증을 검사한다. 일반 검수 계정은
  활성 계정이어야 하며 관리자 계정이면 실패한다. `--models-only`는 서비스 준비 판정이 아니다.
- CLI는 `DLP_REVIEW_POLICY_FILE`로 별도 검수 정책을 선택할 수 있다. 잘못된 파일을 기본 정책으로
  대체하지 않는다. 라이브러리의 기본 정책과 테스트는 환경 변수의 영향을 받지 않는다.
  후속(F-REV-01): CLI는 고른 정책의 `cvat`·`media`를 `ReviewSetup`에도 넘긴다. 전에는 작업 생성의
  CVAT 계정 연결·워터마크 매체 설정만 `ReviewSetup` 지연 로더로 Git 기본값을 읽어, 준비 검사를
  통과한 계정 연결로도 블러 검수 작업을 만들 수 없었다.
- 설치 패키지 공개 취약점 검사에서 PyMongo 4.9.2의 취약점 4건을 확인했다. FiftyOne 1.22.1은
  `pymongo~=4.9.2`, `motor~=3.6.0`을 요구하므로 일반 업데이트로 해결되지 않는다. uv의 명시적인
  override로 Motor 3.7.1과 패치된 PyMongo 4.18.3을 잠금 파일에 고정했다. MongoEngine은 PyMongo
  <5를 허용한다. 실제 FiftyOne 필드·라벨 CRUD 왕복과 Motor 비동기 삽입·집계를 검증한다.
  이는 FiftyOne의 상위 버전 요구를 프로젝트가 대체한 구성이다. 업스트림 핀이 개선되면 이 override를
  제거하는 방향으로 재검증한다. 모든 FiftyOne 기능을 검증하거나 업스트림 지원을 주장하지 않는다.

## 검증과 한계

행 정렬에 맞지 않는 폭 106의 합성 영상에서 RGB 픽셀·연속성을 확인한다. VFR 영상의 0°·±90°·180°
정규화는 프레임 시각뿐 아니라 색 영역의 실제 위치를 검사한다. 다운로드 오타·순환 정책·모델 미준비와
변조된 ZIP 캐시의 회귀 검사를 포함한다. 실제 첨부 영상과 CVAT·DB·저장소의 검증 결과는
`reports/weekend-pilot-readiness.md`에 기록한다.

이 검사는 정확도, 사람 검수 완료, 실제 재학습 효과, 여러 고객의 격리 또는 상용 운영 승인이 아니다.
기본 정책의 `commercial: review`는 법률 검토 완료를 뜻하지 않는다. 첫 파일럿에서는 전신/깊이 3D를
명시적으로 제외하고, 원본 프라이버시 전수 검수와 라벨 검수를 사람이 수행한다.
