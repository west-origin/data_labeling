# 0032 — 탐지 완료·검수 세대·배포와 내보내기 게시의 일관성

상태: 채택 (2026-10-08). 탐지 세대·검수 연결 규칙은 ADR 0033에서 보완했다.

## 배경

전수 검사 결과를 합성 데이터와 임시 PostgreSQL에서 다시 확인했다. 탐지 0건은 라벨 이력에
시각이 남지 않아 이전 검수로 재승인됐고, 서로 다른 검수 작업은 같은 부모를 동시에 수정했다.
완료한 배정의 ID는 새 모델 라벨에도 재사용됐으며 첫 모델 배포가 겹치면 둘 다 deployed였다.
내보내기 파일을 올리는 동안 승인이 취소돼도 완료 manifest가 게시됐다.

## 결정

- `PrivacyDetectionRun` 계약과 추가 전용 `privacy_detection_runs`를 도입한다. 스트림별 실행
  버전과 완료 시각, 증가하는 event_id를 남긴다. 0건도 동일하다. 승인 조건은 완료 시각 이후
  만들어 수집한 운영 전수 검수 작업이며, 배정 세대에는 완료 event_id도 넣는다.
- 구버전 양수 탐지는 모델 블러 라벨의 시각으로 호환한다. 외부 0건 표시만 있으면 다음 detect가
  현재 시각으로 완료 이력을 복구하고 새 검수를 요구한다. DB 롤백 후 남은 표시도 같다.
- 검수 수집은 세션 → 작업 순서로 행을 잠그고 이력을 다시 읽는다. 라벨 삽입·탐지·승인·계획도
  세션 잠금을 사용한다. 여러 세션은 ID 순서로 잠근다.
- 일반 배정 ID도 현재 운영 입력 라벨 집합의 해시로 구분한다. 열린 운영 배정이 있으면 먼저
  끝낸다. 완료 배정 뒤 새 미검수 모델 라벨이 들어왔을 때만 새 세대를 만든다.
- 배포는 과제별 PostgreSQL 트랜잭션 advisory lock 안에서 후보 상태·현재 배포·리포트 비교
  기준을 다시 확인한다. 자동 배포도 리포트 저장소가 필수다. 과제별 deployed 부분 유일 색인이
  저장소 함수 밖의 중복 쓰기도 막는다.
- 내보내기 마지막 게시 단계는 세션 공유 잠금 안에서 현재 사용 중지·프라이버시 승인·블러 해시를
  다시 확인한 뒤 manifest를 올린다. 라벨 삽입과 상태 갱신은 게시 완료까지 기다린다. 실패하면
  미완성 파일과 사전 커밋한 이력은 남지만 완료 manifest는 없다.
- 스냅샷 404는 `SnapshotNotFoundError`로 구분한다. sessions.jsonl이 없는 구버전만 현재 DB로
  대체하며 인증·서버·통신 오류나 일부 세션 누락은 실패시킨다.
- 가명 참조 변환은 `_ids` 배열에도 적용하며 온톨로지 class_id·ref_id는 보존한다.
  공간 궤적은 스트림 시계를 마스터 시각으로
  변환하고 CAMERA 좌표는 동일 스트림끼리만 비교한다. WORLD는 공통 좌표다.
- OWLv2 버전에는 토크나이저 산출물 버전도 포함한다. 빈 평가 결과는 게이트를 통과하지 못하고
  평가 CLI에는 최소 하나의 모델을 요구한다. 0건 승인 영상 감사는 최신 검수 작업의 담당자로
  감사 독립성을 확인한다.

## 이관과 검증

Alembic 0012는 탐지 완료 테이블·수정/삭제/TRUNCATE 방지 트리거·배포 부분 유일 색인을 만든다.
기존 중복 배포가 있으면 색인 생성이 실패한다. 운영자가 올바른 모델을 선택해 나머지를 퇴역시킨
뒤 이관을 재시도한다. 임의로 배포 모델을 선택하거나 과거 0건 실행 시각을 추정하지 않는다.

SQLite는 계약·이관 검사용이며 운영 동시성은 PostgreSQL에서 검증한다. 합성 영상과 임시 DB로
업로드 중 승인 취소·블러 변경, 0건 재탐지, 검수 수집 경쟁, 새 배정과 동시 배포를 회귀 검사한다.
계약 왕복·시간대·참조 무결성과 생성 JSON Schema도 검사한다.
탐지 시각은 UTC로 정규화해 SQLite에서도 입력 시간대와 관계없이 같은 순간으로 왕복한다.

PostgreSQL 헬스체크는 최종 서버에 TCP로 접속해 mlflow DB에서 SELECT 1을 실행한다.
pg_isready가 존재하지 않는 DB에도 성공한다는 점을 확인했으며, 초기 시작 실패라는 이전 추정은
재현하지 못해 철회했다. 손목 속도 설명은 실제 스트림 오프셋을 반영하도록 고친다.
