# ADR 0036: 모델 해시 캐시와 블러 렌더 복구

날짜: 2026-10-10. 상태: 채택. 관련: WP5·WP8, ADR 0024·0035.

## 문제

모델 해시 캐시의 `(경로, float mtime)` 키는 수정 시각을 보존한 덮어쓰기나 파일 교체를
구별하지 못했다. 블러 렌더의 멱등 판정은 입력 해시만 비교해 손상된 실제 출력이나 객체 해시를
복구하지 못했고, 깨진 JSON 기록은 파싱 예외로 재렌더까지 막았다. 렌더에는 세션 잠금이 없어
탐지·검수 수집·승인 변경과 저장소 게시가 겹칠 수 있었다.

## 결정

- 모델 캐시는 파일 시스템 장치·inode·크기·나노초 mtime/ctime을 포함하고 128개로 제한한다.
  해시 읽기 전후의 파일 디스크립터 상태와 캐시 조회 전후의 경로 상태도 확인한다.
- 렌더는 승인/라벨 조회 전에 기존 세션 행 잠금을 잡고 호출자의 트랜잭션 끝까지 유지한다.
  PostgreSQL에서 탐지·수집·승인 변경·내보내기 게시와 같은 잠금 경계를 사용한다.
- 재렌더 생략은 입력 해시, 객체 메타데이터, 다운로드한 실제 바이트 해시가 모두 맞을 때만 한다.
  파일 해시가 없는 이전 출력도 재렌더해 기록을 보완한다. JSON 문법·UTF-8·객체 형태가 잘못된
  기록은 무효로 보고 다시 만든다. 연결·권한 오류는 숨기지 않는다.

## 영향과 검증

DB/공유 계약/모델 가중치/라벨 이력의 변경은 없다. 같은 입력의 정상 출력은 재인코딩하지 않는다.
재실행에도 기존 영상을 내려받아 해시하므로 저장소 읽기 비용과 임시 디스크 사용량이 늘어난다.
렌더 동안 같은 세션의 변경 작업은 기다린다. 대규모 비동기 처리는 별도 설계가 필요하다.

mtime 보존 덮어쓰기·크기 변경·원자적 교체, 정상 출력 생략, 실제 바이트 손상, 객체 해시 변경/누락,
이전 렌더 기록, 잘못된 JSON·JSON 배열·UTF-8을 합성 영상으로 검사한다. 실제 PostgreSQL의 두
연결에서 렌더 트랜잭션이 세션 변경 잠금을 막는지도 검사한다.

stat 기반 캐시는 검증 뒤의 악의적 파일 변경까지 봉쇄하지 않는다. 운영 모델 디렉터리의 쓰기
권한을 제한해야 한다. 저장소 메타데이터는 실제 내용의 대체 검증이 아니므로 소비자의 다운로드
후 해시 검사는 계속 필요하다. 외부 저장소 게시와 DB 커밋은 분산 트랜잭션이 아니다.

## 의존성 패치의 별도 검증

같은 재검수에서 Strawberry GraphQL 0.316.0의 CVE-2026-107727(legacy WebSocket 구독 완료 후
자원 회수)·CVE-2026-107728(특정 awaitable 반환 권한 검사 우회)이 조회됐다. 패치 0.327.2를
설치해 확인했지만, 최신 FiftyOne 1.22.1 서버의 `strawberry.extensions.Extension` import가
실패했다. 따라서 이 override는 제거하고 기존 잠금 버전을 복원했다. 호환되는 패치가 필요하며
두 취약점은 미해결로 보고한다. SDK/CLI 데이터셋 CRUD 검증을 웹 서버 호환성으로 확대 해석하지
않는다. 현재 파일럿 명령은 FiftyOne GraphQL 서버를 시작하지 않는다.
