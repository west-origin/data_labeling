# 전수 검사 2026-10-28: 저장소 전체 (98b7c9d)

pstack swarm·interrogate 방식으로 저장소 전체를 10개 구역으로 나눠 검사했다. 실행으로 증명한 결함만
남겼고, 고치는 일은 검사가 끝난 뒤 따로 했다.

## 방법

- 구역: s1 계약·DB, s2 미디어·동기화, s3 프라이버시, s4 프리라벨 2D, s5 프리라벨 3D, s6 검수, s7 행동·관계·AI 검수,
  s8 데이터셋·내보내기·리타기팅, s9 학습·평가·모델, s10 CLI·콘솔·운영·설치.
- 구역마다 독립 검사자가 저장소를 고치지 않고 코드를 읽고 합성 픽스처·일회용 DB·실제 SeaweedFS로 재현을 돌렸다.
  지적마다 "실제 출력"과 "의도대로라면"을 적었다.
- 취합 단계에서 재현을 다시 돌렸다. 46건 중 42건은 같은 출력을 다시 얻었다. 콘솔 4건(F-COE-79·80·83·84)은
  검사자의 HTTP 실행 결과와 코드 대조로 확인했다.
- 돌려서 증명하지 못한 의심(구역마다 약 5건)은 등록하지 않았다. CVAT가 꺼져 있어 CVAT 화면에서의 동작은
  보지 못했다.
- 같은 원인 둘은 한 ID로 합쳤다: 계약의 NaN·Inf(s1)와 `dlp sync adjust nan`(s2)은 F-SCH-27.
