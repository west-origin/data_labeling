# 운영 안내서 (운영 콘솔)

[인수인계 첫 화면](README.md) · [설치 스크립트](../../scripts/install/README.md) · [ADR 0061](../adr/0061-operator-console.md)

이 안내서는 개발자가 아닌 운영자 한 명이 브라우저 화면(운영 콘솔)으로 영상을 올리고, AI 초안을 고치고,
모델을 다시 학습시키는 순서를 설명한다. 콘솔은 새 기능을 만들지 않는다. 버튼마다 이미 있는 `dlp` 명령을
대신 실행하고 결과를 보여 줄 뿐이다. 그래서 같은 버튼을 다시 눌러도 안전하다 (이미 된 일은 건너뛴다).

## 1. 설치 (처음 한 번)

1. Docker를 설치하고 켠다 (Mac·Windows: Docker Desktop, Windows는 WSL2 안의 Ubuntu에서 진행).
2. 저장소 폴더에서 `scripts/install/install.sh --check-only`로 점검하고, 통과하면
   `scripts/install/install.sh --install-uv --with-cvat`를 실행한다. 단계마다 `[확인]`·`[주의]`·`[실패]`가
   찍힌다. `[실패]` 아래의 "할 일"을 하고 같은 명령을 다시 실행하면 된 단계는 건너뛴다.
3. 검수 계정을 정한다. 블러 검수(원본 영상을 보는 일)는 **원본 접근 권한자**만 할 수 있다. 개발자에게
   검수 정책 파일(`config/policies/review.yaml`을 복사한 파일)에 `reviewers.privacy`, `cvat.users`,
   `label_studio.users`를 적어 달라고 하고, 그 파일 위치를 `.env`에 `DLP_REVIEW_POLICY_FILE=…`로 적는다.
   라벨 검수 담당자 이름을 미리 넣으려면 `DLP_CONSOLE_LABELER=<검수자 ID>`도 적는다.
4. `uv run dlp console serve`를 실행하면 `운영 콘솔: http://localhost:8090/#token=…`이 찍힌다. 그 주소를
   그대로 브라우저로 연다. 주소의 토큰은 실행할 때마다 바뀐다. 다른 사람에게 주소를 보내지 않는다.
   콘솔은 이 컴퓨터에서만 열린다 (다른 컴퓨터에서 여는 것은 개발자와 상의, `--allow-remote`).

## 2. 화면 구성

| 탭 | 하는 일 |
| --- | --- |
| 세션 | 왼쪽: 세션 목록. 오른쪽: 고른 세션의 파이프라인 카드(1~13단계), 결과 보기, 이 세션의 작업 |
| 영상 올리기 | 영상 파일과 최소 정보로 새 세션을 만든다 (준비·수집까지 자동) |
| 학습·성과 | 데이터셋 버전, 재학습(골든셋 게이트), 배포 승인, 회차별 골든셋 지표 그래프, 주별 수정률 그래프 |
| 가중치 가져오기 | Colab·Kaggle에서 공개 데이터로 학습한 가중치 검사·기록, 골든셋 비교, closed_tools 켜기 안내 |
| 작업 기록 | 지금까지 누른 버튼(작업)의 상태·마지막 오류·다음 할 일·로그 |

오른쪽 위 버튼으로 다크/화이트를 바꾼다 (검수 화면과 같은 색). 키보드 Tab으로 모든 버튼에 갈 수 있다.

파이프라인 카드의 상태: **완료**(초록 체크), **실행 가능**(파란 버튼), **대기**(빨강, 아래 노란 글이 이유),
**건너뜀**(사내 VLM 서버가 없을 때 등). 작업이 돌고 있으면 그 세션의 버튼은 모두 잠기고 4초마다 화면이
새로 고쳐진다.

## 3. 첫 영상

1. **영상 올리기**: 세션 ID(새 이름, 이미 쓴 ID는 다시 쓰지 않는다), 작업자·장소 가명 ID, 도메인, 장면,
   **실제로 확인한 동의서 버전**(모르면 올리지 않는다), 촬영 시각(있으면), 카메라 기기 ID(있으면).
   스마트폰을 가슴에 거꾸로 달았으면 촬영 방향 회전 180°를 고른다 (착용자 몸·팔이 화면 아래에서 들어와야
   한다). "올리고 수집 시작"을 누르면 작업 기록 탭으로 간다. 수집이 끝나면 올린 사본은 지워진다.
2. **세션 탭에서 고르기** → 1 동기화(스트림이 하나면 이미 완료) → 2 **블러 탐지**. CPU에서는 영상 길이의
   수십 배가 걸릴 수 있다 (6분 영상에 1시간 이상).
3. 3 **블러 검수 작업 만들기**: 담당자(원본 접근 권한자)를 고르고 실행. CVAT가 켜져 있어야 한다. 카드 아래
   "CVAT에서 열기"로 작업을 연다. 영상 **전체**를 보며 빠진 얼굴·문서·화면을 더하고 잘못된 블러를 지운 뒤
   CVAT에서 작업을 완료한다. 탐지가 0개여도 영상 전체를 본다.
4. 4 **블러 검수 결과 수집** → 5 **블러 승인**(확인 대화에서 "예"는 직접 확인했을 때만) → 6 **블러본 만들기**.
5. 7 **AI 1차 라벨**: 긴 영상은 "빠르게(전신·깊이 3D 빼기)"로 먼저 돌린다. 끝나면 8 관계 도출,
   9 행동 구간·10 AI 1차 검수(사내 VLM 서버가 있을 때만, 없으면 "건너뜀").
6. **결과 보기**: 라벨 종류·출처·검수 상태별 개수, "블러본 위에 라벨 보기"로 블러본 영상 위에 박스·손
   점을 겹쳐 본다 (노랑 = 아직 사람이 보지 않음, 초록 = 검수됨). 원본 영상은 이 화면에 나오지 않는다.

## 4. 고치기 (사람 검수)

1. 11 **라벨 검수 작업 만들기**: 담당자와 도구(CVAT + Label Studio, CVAT가 꺼져 있으면 Label Studio만)를
   고른다. 카드 아래 링크로 도구를 연다. CVAT: 손 관절·좌우·객체 박스·클래스. Label Studio: 시간 구간.
   **담당자 계정으로** 고치고 제출한다 (다른 계정의 주석은 받지 않는다).
2. 12 **라벨 검수 결과 수집** → 13 **검수 완료**. 아직 완료가 아니면 작업 기록의 "마지막 오류"에 남은
   사유가 보인다. 사유를 해결하고 다시 누른다.

## 5. 다시 학습 (학습·성과 탭)

1. **데이터셋 버전 만들기**: 버전 ID(예: `ds-2026-11-01`), 골든셋(있으면). 검수 완료된 세션만 들어가고
   작업자·장소가 학습·검증·골든 사이에 겹치지 않게 나뉜다.
2. **재학습(골든셋 게이트)**: 과제(objects·hands 등)와 데이터셋 버전. 학습 → 골든셋 평가 → 게이트 판정.
   통과하면 정책대로 바로 배포되거나 "게이트 통과(승인 대기)"가 되고, 표의 **배포 승인** 버튼으로 배포한다.
   첫 배포 전에는 "처음 비교할 기본 모델 버전"이 필요할 수 있다 (개발자에게 묻는다).
3. 그래프: 과제마다 회차별 골든셋 지표(초록 점 = 게이트 통과, 빨강 = 실패). **"시험용 학습기" 배지**가
   있으면 그 지표는 실제 성능이 아니다 (CI용 oracle-stub 학습기). 주별 **수정률**은 "주간 운영 지표"를
   눌러 다시 계산한다. 수정률이 내려가면 사람이 AI 초안을 덜 고친다는 뜻이다.

## 6. 외부에서 학습한 가중치 가져오기

1. Colab(`scripts/pretrain/objects_pretrain.ipynb`)에서 공개 데이터만으로 학습하고 `ckpt/export/`의
   ONNX·`model_manifest.json`·`data_manifest.json`을 내려받는다. **우리 영상·라벨은 Colab에 올리지 않는다.**
2. 세 파일을 올리고 **검사하기**. 모든 줄이 "통과"여야 한다 (해시·클래스 순서·decode 끔·데이터셋 라이선스).
   `config/models.yaml`에 넣을 내용이 미리보기로 나온다. **확인하고 기록**을 누르면 가중치를
   `data/models/pretrain/`에 두고, 개발자가 실행할 명령(`git apply …`, `make licenses`)을 보여 준다.
   콘솔은 설정 파일을 직접 고치지 않는다 (Git 검토를 거친다).
3. **골든셋 비교**는 YOLOX 학습기가 연결된 뒤에 켜진다 (지금은 꺼져 있고 이유가 보인다, F-COE-74).
   비교에서 게이트를 통과하면 closed_tools 단계를 켜는 설정이 화면에 나온다. 통과 전에는 켜지 않는다.

## 7. 자주 나는 오류

| 화면에 보이는 것 | 할 일 |
| --- | --- |
| "콘솔 토큰이 없거나 틀립니다" | 콘솔을 다시 켰다면 새로 찍힌 주소로 다시 연다 |
| "CVAT가 꺼져 있습니다" | 터미널에서 `make cvat-up` (처음이면 `make cvat-superuser`). Label Studio만 쓰려면 도구를 "Label Studio만"으로 |
| "reviewers.privacy에 원본 접근 권한자가 없습니다" | 1절 3번의 검수 정책 파일을 준비한다 |
| "DB(PostgreSQL)에 연결하지 못했습니다" | `make up` 뒤 `make health` |
| "저장 공간이 부족할 수 있습니다" | 디스크를 비운다 (원본·DB 볼륨은 지우지 않는다), `docker restart dlp-seaweedfs-1` |
| "모델 가중치가 없습니다" | `make models` |
| "같은 세션 ID가 다른 내용으로 이미 있습니다" | 새 세션 ID로 다시 올린다 |
| "이미 실행 중인 작업이 있습니다" | 그 작업이 끝날 때까지 기다린다 (작업 기록 탭) |
| 작업이 "중단됨" | 콘솔이 꺼졌던 작업이다. 상태를 보고 같은 버튼을 다시 누른다 |
| "이미 올린 사본이 있습니다" | 진행 중이면 기다리고, 실패했으면 작업 기록의 "업로드 사본 지우기" 뒤 다시 올린다 |
| 경고 `low_fps`·`no_imu`·`no_device` | 막지 않는 촬영 점검 경고다 ([촬영 안내](capture-guide.md)) |

작업 로그·업로드 사본은 `~/.dlp-console`(또는 `DLP_CONSOLE_DIR`)에 있다. 로그 화면은 원본 위치와 비밀번호를
가려서 보여 준다. 그래도 로그 파일 자체를 다른 사람에게 보내지 않는다.
