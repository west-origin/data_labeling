# 전수 검수 2026-10-17: 손끝 3D ~ 로봇 리타기팅·물리 사전값 (beabdeb^..51a4660)

범위는 커밋 22개(파일 139개)다. 단안 손끝 3D(ADR 0044), 표본 신뢰도·캘리브레이션·작업자 손 크기(0045),
바디캠 자세·월드 좌표(0046), 로봇 리타기팅(0047), 3D 궤적 검수 물려받기·회수·자동 자세(0048·0050),
온톨로지 물리 사전값(0049), CLAUDE.md 갱신을 다룬다.

## 방법

- 8개 영역(손 맞춤, 캘리브레이션, 자세·월드, 리타기팅, 궤적 따르기, 물리 사전값, 규칙·문서, 단계 사이 흐름)을
  독립 검수자가 읽기 전용으로 보고, 지적마다 반박을 시도하는 검증자를 두 번(서로 다른 실행) 붙였다.
- 완결성 비평 뒤 4개 대상(월드 단계의 비2D 입력, 온톨로지 이관과 3D 계약, 작업자 손 크기 수명, LeRobot 사람 모드 계약)을
  더 봤다. 숫자가 아닌 값(NaN)의 DB 유입과 원본 삭제 뒤 3D 재생성은 수정 단계에서 함께 확인한다.
- 지적 95건 가운데 두 검증이 모두 반박한 것은 뺐다. 영역끼리 겹친 지적은 한 ID로 합쳤다.
